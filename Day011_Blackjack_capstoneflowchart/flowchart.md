flowchart TD
    A([Start]) --> B[ゲームをプレイするか確認]
    B --> C{play == y?}
    C -- No --> Z([End])
    C -- Yes --> D[ロゴを表示]
    D --> E[プレイヤーにカードを2枚配る]
    E --> F[コンピュータにカードを1枚配る]
    F --> G[両者のカードを表示]
    G --> H[追加カードを引くか確認]
    H --> I{another_card == y?}

    I -- Yes --> J[プレイヤーにカードを1枚追加]
    J --> K[プレイヤーのスコアを計算]
    K --> L{スコア > 21?}
    L -- Yes --> M[プレイヤーの最終カードとスコアを表示]
    M --> N[コンピュータのカードとスコアを表示]
    N --> O[You went over. You lose!]
    L -- No --> P[カードを引くか再確認]
    P --> I

    I -- No --> Q{プレイヤーのスコア <= 21?}
    Q -- No --> R[プレイヤーの負けを表示]
    Q -- Yes --> S[コンピュータのスコアを計算]
    S --> T{スコア < 17?}
    T -- Yes --> U[コンピュータにカードを1枚追加]
    U --> S
    T -- No --> V[両者の最終カードとスコアを表示]

    V --> W{コンピュータのスコア > 21?}
    W -- Yes --> X[You win!]
    W -- No --> Y{両者のスコアは同じ?}
    Y -- Yes --> Y1[Draw!]
    Y -- No --> Y2{プレイヤーのスコア < コンピュータのスコア?}
    Y2 -- Yes --> Y3[You lose!]
    Y2 -- No --> Y4[You win!]

    O --> AA[もう一度プレイするか確認]
    R --> AA
    X --> AA
    Y1 --> AA
    Y3 --> AA
    Y4 --> AA
    AA --> C
